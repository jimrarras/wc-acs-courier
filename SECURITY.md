# Security policy

## Supported versions

Only the latest release of ACS Courier for WooCommerce receives security fixes.

| Version | Supported |
|---|---|
| 1.3.x | Yes |
| Older releases | No |

## Reporting a vulnerability

Please do not open a public issue for a security problem.

Report it privately through GitHub: open the **Security** tab of this repository and choose **Report a vulnerability**. Include the plugin version, your WordPress, WooCommerce and PHP versions, the steps to reproduce, and the impact you expect.

You will get an acknowledgement within 7 days. When a fix is released, the report is disclosed with credit to the reporter, unless you ask otherwise.
